# README Bilingual Guide / README 双语指南

## Style / 风格

Use paired English and Chinese sections. Keep the first screen concise and clear.

首页要让人马上理解：

1. 这不是普通排盘器；
2. 这是 deterministic BaZi derivation + context-aware forecast + evaluation benchmark；
3. AI 不参与定盘；
4. 用户数据 local-first；
5. 项目是 research prototype，不承诺玄学确定性。

## Recommended README structure / 推荐结构

1. Title / 标题
2. Tagline / 一句话定位
3. Why this exists / 为什么做
4. Core formula / 核心公式
5. What makes it different / 差异点
6. Architecture / 架构图
7. Tech stack / 技术栈
8. AI boundary / AI 边界
9. Quick start / 快速开始
10. Evaluation modes / 评估模式
11. Privacy / 隐私
12. Limitations / 局限

## Messaging discipline / 表达边界

Do say:

- context-aware forecast;
- user-controlled context profile;
- deterministic chart derivation before AI;
- holdout benchmark modes;
- local-first privacy.

Do not say:

- hidden unfair advantage;
- questionnaire trick;
- secretly reusing answers;
- guaranteed accuracy;
- medical/legal/financial certainty.

## Chinese positioning / 中文定位建议

## English positioning / English positioning

> A local-first BaZi research prototype exploring personalized forecasting through deterministic chart derivation, candidate rectification, user-controlled context, and structured evaluation.
