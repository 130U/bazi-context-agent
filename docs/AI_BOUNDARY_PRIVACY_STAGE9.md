# AI Boundary and Privacy / AI 边界与隐私

## AI boundary

AI is allowed in forecast and report generation only after deterministic inputs exist.

AI must not:

- decide birth hour;
- modify chart ranking;
- modify rectification result;
- change selected chart;
- alter BaziDerivedProfile;
- change ForecastInput;
- expose API keys;
- write hidden user data to public files.

## Privacy boundary

User context can personalize forecasts, but users must control:

- whether data is saved;
- what facts are used in forecast;
- what facts are included in export;
- what facts are deleted;
- whether reports are redacted.

## Public wording

Use: “user-controlled context profile”.

Avoid: “hidden questionnaire trick”.
