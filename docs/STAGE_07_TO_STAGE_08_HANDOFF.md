# Stage 7 to Stage 8 Handoff

After Stage 7, the project has:

```text
forecast engine + evaluation harness
```

Stage 8 should focus on:

```text
privacy, local storage, user control, safe data handling
```

Specifically:

- local-first sessions
- delete context fact
- hide context fact from forecast
- export session JSON
- clear session
- privacy notice
- redaction policy
- no cloud database by default

Do not start Stage 8 until Stage 7 benchmark runner is stable.
