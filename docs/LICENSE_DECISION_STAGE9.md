# License Decision / 许可证决策

A GitHub repository without a license is not truly open source for reuse. Before making the repository public, decide whether this project is:

1. open-source;
2. source-available;
3. private research;
4. dual-license.

## Recommended policy for now

If the business strategy is not settled, do not auto-add MIT/Apache/GPL. Instead:

- keep README license section as TBD;
- document that no reuse rights are granted until a license is selected;
- add LICENSE only after explicit approval.

## Common options

- MIT: permissive, simple.
- Apache-2.0: permissive with patent grant.
- AGPL/GPL: copyleft, not recommended unless intentional.
- Proprietary/source-available: protect commercial logic.
