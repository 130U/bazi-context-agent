# Stage 09 Roadmap — GitHub Release Polish / GitHub 发布包装

## Position / 当前阶段定位

Stage 9 is the release-polish layer. It does not modify deterministic chart logic, rectification, forecast logic, evaluation scoring, privacy controls, or provider behavior.

Stage 9 是发布包装层，不修改定盘、校盘、预测、评估、隐私控制或 provider 行为。

## Objective / 目标

Prepare the repository for GitHub presentation with:

1. bilingual README;
2. clear product positioning;
3. architecture overview;
4. tech stack explanation;
5. AI boundary explanation;
6. privacy and key-safety documentation;
7. evaluation explanation;
8. contribution/security files;
9. release checklist.

## Non-disclosure boundary / 不展开的内容

Public docs may describe the high-level architecture:

- deterministic chart derivation;
- context-aware forecast;
- local-first privacy;
- holdout evaluation.

Public docs should not expose:

- scoring weights beyond already public configs;
- internal prompt recipes;
- private benchmark cases;
- proprietary weighting heuristics;
- wording that frames questionnaire context as a hidden tactic.

The correct public language is: **user-controlled context profile used for personalization and evaluation**.

正确公开口径：**用户可控上下文信息用于个性化预测和评估**。
