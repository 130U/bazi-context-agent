# Stage 4C UI and Report Polish

Stage 4C improves prediction display and report export.

## UI sections

The prediction UI must show:

1. Conclusion.
2. Known facts.
3. Chart signals.
4. Context adjustments.
5. Prediction answer.
6. Confidence.
7. Uncertainty.
8. Next questions.
9. Policy metadata.

## Report preview

The report should include:

1. Ranking summary.
2. Context box summary.
3. Prediction result.
4. Policy boundary notice.
5. Generated timestamp.

## Export

Allowed:

- JSON export.
- Markdown export.

Not allowed in Stage 4C:

- PDF generation.
- DOCX generation.
- Cloud storage.
- Login/account system.
