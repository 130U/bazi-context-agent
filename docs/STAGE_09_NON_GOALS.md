# Stage 9 Non-Goals

Stage 9 must not:

1. modify chart derivation;
2. modify rectification scoring;
3. modify forecast output logic;
4. change provider behavior;
5. create a real `.env` file;
6. write real API keys;
7. add login, payment, database, or user accounts;
8. expose internal scoring heuristics;
9. claim guaranteed accuracy;
10. make the repository public automatically;
11. choose a license without explicit approval.
