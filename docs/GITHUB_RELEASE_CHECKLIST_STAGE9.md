# GitHub Release Checklist / GitHub 发布检查清单

## Required before public release

- [ ] README.md is bilingual.
- [ ] README explains product uniqueness without exposing proprietary heuristics.
- [ ] README contains quick start.
- [ ] README contains AI boundary.
- [ ] README contains privacy and limitations.
- [ ] Issue templates exist.
- [ ] `.env` files are ignored.
- [ ] Example env files contain no real keys.
- [ ] npm test passes.
- [ ] No real API key is present.
- [ ] No private user data is present.
- [ ] Demo instructions work.
- [ ] Stage status table is current.

## Optional before public release

- [ ] Add screenshots or GIF.
- [ ] Add architecture diagram image.
- [ ] Add GitHub topics.
- [ ] Add roadmap issue.
- [ ] Add release tag.
