# Stage 4A Deliverables

Stage 4A implements the prediction architecture with a mock provider only.

## Required deliverables

1. Prediction TypeScript types.
2. Deterministic prediction domain classifier.
3. Context box normalization helpers.
4. Prediction prompt builder or provider input builder.
5. Mock prediction provider.
6. Prediction policy guard.
7. `POST /api/prediction`.
8. Minimal UI area after ranking result.
9. Tests covering schema, policy, and boundary behavior.

## Non-deliverables

1. No real OpenAI API.
2. No API key.
3. No `.env` real file.
4. No database.
5. No login or payment.
6. No new UI framework.
7. No real BaZi calendar engine.
