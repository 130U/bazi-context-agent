# Stage 8 Non-Goals

Stage 8 must not implement:

- cloud sync;
- accounts;
- login;
- auth;
- payment;
- database;
- server-side user profiles;
- analytics tracking;
- multi-device sync;
- team collaboration;
- legal certification;
- HIPAA/GDPR/PDPA compliance claims;
- new forecast models;
- new ranking logic;
- new rectification logic;
- new BaZi engine adapters;
- React / Next / Vite / Vue / Svelte migration.

Stage 8 is only about privacy controls, local session state, export/import, redaction, and user control.
