# Stage 09 README Strategy

## Goal

The GitHub homepage README must explain the project's distinctiveness without exposing internal scoring details or proprietary feature mappings.

## Public message

Say:

- This is a deterministic-first BaZi rectification and context-aware forecasting prototype.
- The system separates derived BaZi structure from real-world context.
- AI is only used after chart selection for forecasting and explanation.
- The system uses evaluation modes to avoid confusing known facts with prediction.
- The system is local-first and privacy-aware.

Do not say:

- The exact questionnaire-to-forecast feature mapping.
- Exact hidden weights or internal prompt orchestration.
- Private benchmark cases.
- Any statement implying the questionnaire is a covert data collection trick.
- Any unsupported accuracy claim.

## Required bilingual style

The main `README.md` should be bilingual, with Chinese and English close together so GitHub visitors can understand the project without switching files. Keep `README.zh-CN.md` and `README.en.md` as short companion files.

## Positioning phrase

Recommended tagline:

> Deterministic BaZi rectification + structured context + bounded AI forecasting.

中文：

> 确定性八字校盘 + 结构化现实上下文 + 有边界的 AI 预测。
