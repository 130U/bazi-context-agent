# Bilingual README Guide

## Main README style

Use bilingual paired sections:

```md
## Why this project exists / 为什么做这个项目

**中文**
...

**English**
...
```

For short comparisons, use two-column tables:

```md
| 中文 | English |
|---|---|
| ... | ... |
```

## Required sections

1. Project title
2. One-sentence bilingual tagline
3. Why this project exists
4. What makes it different
5. Architecture diagram
6. Current capabilities
7. Tech stack
8. Quick start
9. Environment variables
10. Evaluation modes
11. Privacy model
12. What this project is not
13. Repository map
14. Development rules
15. Contributing
16. License decision

## Tone

Clear, technical, calm. Do not oversell accuracy.
