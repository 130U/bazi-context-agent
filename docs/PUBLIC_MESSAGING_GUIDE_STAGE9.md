# Public Messaging Guide — Stage 9

## Core public thesis

This project explores a two-part forecasting pipeline:

```text
BaZi-derived structure + user-controlled context → structured forecast
```

## What to emphasize

- Deterministic chart derivation before AI.
- Context-aware but user-controlled forecasting.
- No AI in ranking or rectification.
- Local-first privacy controls.
- Evaluation modes A/B/C/D.
- Experimental and research-oriented nature.

## What not to expose

- Internal scoring strategy beyond public docs/configs.
- Private prompt engineering recipes.
- Private benchmark cases.
- Exact heuristics for extracting context advantage.
- Any phrasing that suggests deception.

## Ethical transparency minimum

Do not mislead users. Public docs should acknowledge that user-provided context can be used to personalize forecast output. The proprietary part is how the system structures, gates, weighs, and evaluates that context.
