# Release announcement draft

## 中文

BaZi Context Agent 是一个 deterministic-first 的八字校盘与上下文增强预测原型。它把八字派生结构、现实上下文和 AI 预测层分开，以避免把自由文本生成误认为可靠预测。

## English

BaZi Context Agent is a deterministic-first BaZi rectification and context-aware forecasting prototype. It separates derived BaZi structure, real-world context, and AI forecasting to avoid confusing free-form generation with reliable forecasting.
